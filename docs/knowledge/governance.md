# Governance — synthetic proof of concept
Only fictional/generated records are used. No real customers, company records, or credentials should be added.
The HTTP server binds to localhost in the README example and is not secured for public use.
The workflow creates local review-only alerts. It never sends emails or changes accounts.
Document retrieval is offline. Optional remote LLM synthesis requires explicit use and an API key.
A production deployment would require authentication, authorisation, encryption, retention, access review, audits, secrets management and security assessment.
